# 氛围与视觉规范

## 0. 先定隐喻

整站只服从一个隐喻：**放映单 / 卷**。你打开的是影院门口那张排片表和你手里的场刊，不是商品列表。

由此推出三条不可协商的结论：

1. 信息以**行**组织，不以卡片组织。卡片是电商语言，排片表是行。
2. 编号是结构的一部分，不是装饰。`No.001` 必须和片名同级显眼。
3. 动效只允许"光线变化"类，不允许"界面位移"类。

备选隐喻（如果放映单做腻了）：胶片齿孔（用齿孔做滚动刻度）、场记板（用打板做页面切换）。二者只换皮，不换上面三条。

## 1. 色彩 token

| token | 值 | 用途 | 约束 |
|---|---|---|---|
| `--ink` | `#0B0B0C` | 页面底 | 近黑不纯黑，留一点暖 |
| `--ink-2` | `#131215` | 卷标背景、悬浮区 | 与底差 3–5% |
| `--paper` | `#E8E4DA` | 主文字 | 对比度 ≥ 12:1 |
| `--paper-dim` | `#9A948A` | 次要文字、元数据 | 对比度 ≥ 4.5:1 |
| `--accent` | `#C8552B` | 唯一强调色：当前卷、打卡、焦点环 | 全站只用一种 |
| `--film-*` | 运行时注入 | 每部片海报主色，只用于编号列与左竖线 | 饱和度限幅 |

硬规则：

- **只有一种强调色**。颜色预算全部让给电影本身——海报主色是唯一的"彩色来源"。
- 电影主色只出现在**一个元素**上（该行编号与 1px 左竖线），不铺背景、不进按钮。
- 未看的行整体 `opacity:.55`，看过恢复 `.95`；**颜色随打卡增长**，这是全站唯一的情绪曲线。

## 2. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 编号、年份、片长、技术栏 | 等宽（IBM Plex Mono / JetBrains Mono） | 数字必须等宽，榜单才立得住 |
| 中文片名、卷标题 | 宋体（思源宋体 / 霞鹜文楷） | 只用一个字重 + 一个细字重 |
| 英文片名 | 衬线（EB Garamond / Cormorant） | 与中文宋体视觉同族 |
| 正文、手记 | 黑体（思源黑体） | 手记可用文楷增加手感 |

只用两对，不再增加。禁止：艺术字、手写体、字重超过三档的字体家族。

排版规则：

- 片名中英并排：中文在前，英文小一号、`--paper-dim`，基线对齐。
- 编号 `No.001` 用 tabular-nums，千位对齐。
- 行高：列表行 1.35；手记 1.8（手记要松）。
- 中文与数字/英文之间插入 1/4 空格（`\u2009`），全站统一。

## 3. 列表行版式（核心组件）

```
┌──────┬──────────────────────────────┬──────┬────────┬──────┬──────┐
│ No.001│ 教父  The Godfather           │ 1972 │ 科波拉 │ 175′ │ 美国 │
└──────┴──────────────────────────────┴──────┴────────┴──────┴──────┘
```

- 网格：`76px | 1fr | 64px | 1fr | 56px | 72px`，窄屏（<560px）降为两行：编号+片名 / 元数据行。
- 行高 64px（桌面）/ 72px（移动，便于触控）。
- 悬停：整行底色 `--ink-2`，海报缩略图从行右侧淡入（160ms），编号换成该片主色。
- 分隔线：1px `rgba(232,228,218,.08)`，不用斑马纹。
- 不显示简介、不显示主演——想了解就进详情。

## 4. 卷（每 10 部）

- 卷标是 `01–10 · 第一卷：黑暗的秩序`，字重轻、字距宽。
- 滚动进入下一卷时，卷标从上方淡入并短暂吸顶（1.2s 后解除），**不做视差位移**。
- 卷标题由人工命名，写进 `lists/*.json` 的 `chapters`，不允许自动生成。

## 5. 七个机制（照做即成立）

1. **编号即结构**：等宽、`--paper-dim`、悬停变主色。
2. **信息密度拉满、简介清零**：一行六列，没有摘要。
3. **十部一卷 + 人工卷名**：低成本的刊物感，也是最容易被抄不走的部分。
4. **颜色从电影里长出来**：构建期取主色，运行时只做 CSS 变量注入。
   - **元数据统一规格**：编号、年份、导演、时长、国别共用一套字体（等宽 11.5px）与 `line-height: 1`；盒子高度等于字号，行内居中即对齐。任何一列都不允许再用 `top`/`margin` 做像素补偿。
   - **唯一的偏移量**：英文原名作为副标题，统一 `--sub-offset: 3px`（基线下沉，形成主次）。除此之外全站没有第二个手工垂直偏移。
5. **三种动效**：溶解（300ms opacity）、推近（悬停 8s `scale(1→1.06)`）、卷标淡入。禁止位移、缩放弹跳、视差滚动。
6. **颗粒是底噪**：全屏 SVG noise，`opacity:.04`，`position:fixed`，不随滚动。不要加扫描线——贯穿屏幕的横线会读成脏点。
7. **打卡是盖章**：看过之后落一枚票根戳（±3° 旋转、`--accent` 半透明、带盖章日期），行内不出现"已看"文字标签。

## 6. 首页开场（前 3 秒的分镜）

| 时间 | 画面 | 目的 |
|---|---|---|
| 0–0.4s | 纯 `--ink` 底 + 颗粒浮现 | 灯暗下来 |
| 0.4–1.0s | 站名以宋体淡入，字距从 0.3em 收紧到 0.12em | 像片头字幕 |
| 1.0–1.6s | 一行小字：`影史前一百 · 按口径分卷` | 立刻说清这是什么 |
| 1.6s 起 | 卷目录自下而上溶解进场（每卷错开 60ms） | 进入放映单 |

约束：总时长 ≤ 2s 才能进入可操作状态；用户滚动或按键立即跳过；不允许全屏加载动画、不允许倒计时数字。

## 7. 详情页：一场放映

从上到下、只有六段：

1. **全屏静帧**（一张剧照，铺满，暗角压边）。
   - 剧照位右侧放海报/剧照：宽 46%，向左渐隐遮罩，透明度 0.5，轻微降饱和；接真海报时只换素材，版式不变。
   - 无剧照时用「巨幅描边字」占位：**左对齐，与正文同一条左边界**，向右铺满（SVG `textLength` 精确拉满整行，与字体是否加载无关）。
   - 描边字内容 = **英文原名**（无英文名回退年份），主标题只放中文片名——同一信息全页只出现一次。
   - 展示字体用 Cinzel（SIL OFL 1.1，内联为 data URI 保证首帧可用）；字号由 `textLength` 控制，短标题按 6 字基准等比收窄。
   - 「类型 · 榜单名次」放在主标题行右侧，与「年份 · 导演」同一行字体（衬线斜体、次要色）；描边字下方不挂任何小字。
   - 间距：剧照位上内边距 76px，描边字与主标题之间 `clamp(40px, 7vh, 88px)`，不再挤压也不留大片空白。
2. **一句话台词**（或一句影评摘句，标来源）。
3. **技术栏**（等宽小字，一行：片长 / 画幅 / 声音 / 彩色或黑白 / 国别 / 语言）。
4. **策展手记**（150–300 字，第一人称，写"为什么它在榜上"）。
5. **获奖记录**（按 `tier` 分组的紧凑列表，A 级在前，最多显示 6 条，其余折叠）。
6. **打卡按钮**（唯一的主按钮，文案随机三选一："看过" / "已入场" / "盖戳"）。

正文**单栏**，最大阅读宽度 68ch（不再有右栏：榜单坐标已在标题行右侧、获奖在正文里，重复信息不另立面板）。

打卡按钮**紧跟主标题右侧**，与标题**底边对齐**，总高度压在标题字号以内（17px × 1.35 + 内边距 ≈ 43px < 64px）。「类型 · 榜单名次」放在下一行（年份 · 导演行）的最右端，与左侧信息两端对齐。盖章后按钮弱化为「已入场」，日期与「仅存本机」显示在该行下方。窄屏时标题可折行，按钮固定在右侧。

首屏的剧照位右侧放海报/剧照（宽 46%，向左渐隐遮罩，透明度 0.5，轻微降饱和）；接真海报后这块替换素材即可，版式不变。

主演、完整简介、演职员表放在最底部折叠区。**默认不展开**。

## 8. 声音

- 默认静音。只有用户点开右上角喇叭才播放。
- 音源：极轻的放映机底噪（循环，`-24 LUFS` 以下），切卷时轻微"换卷"声。
- 不允许进入即播放、不允许 autoplay、不允许音效打断阅读。

## 9. 可访问性底线

- 正文对比度 ≥ 7:1，次要文字 ≥ 4.5:1；`--paper-dim` 在 `--ink` 上实测 4.6:1，不要再压。
- 暗色主题下海报主色必须限幅（亮度 35–65%、饱和度 ≤ 60%），否则用作文字色会失效。
- 焦点环：`2px --accent` + 2px offset，键盘可达；列表是 `<ol>`，行是 `<li>`，不造假 div 列表。
- 打卡状态不能只靠颜色区分：同时给 `aria-pressed` 与戳记的形状（有戳/无戳）。
- 尊重 `prefers-reduced-motion`：关闭推近与溶解，只保留 80ms 淡入；颗粒降到 `.02`。

## 10. 反模式（出现即打回）

- 卡片网格 + 大图 + 简介（这就是"又一个电影推荐站"）
- 荧光色、渐变按钮、玻璃拟态
- 悬浮时整行缩放或位移动画
- 用 emoji 当图标
- 自动播放预告片或音乐
- 把评分做成星级
- 把"已看"做成绿色对勾
- 滚动视差超过 8%

## 11. 落地顺序

`tokens.css`（颜色+字体） → 列表行组件 → 卷标 → 首页开场 → 详情页 → 盖章动效 → 颗粒与声音。每一步截图验收，不点头不进下一步。
