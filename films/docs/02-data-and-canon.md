# 数据与口径

## 1. 数据分三层，别混

| 层 | 内容 | 来源 | 可信度 |
|---|---|---|---|
| 客观 | 年份、片长、国别、语言、导演、类型、画幅、默片/彩色 | TMDb 主源，缺则人工补 | 高，可复核 |
| 争议 | 评分 | IMDb / 豆瓣 / Letterboxd 三源并存 | 中，取决于人群 |
| 立场 | 「最伟大」、类型归属、值不值得看 | 权威榜单 + 本项目的策展 | 低，但必须透明 |

规则：**客观字段不许猜，争议字段不许合并，立场字段必须署口径。** 三者混在一起，榜单就失去可信度。

## 2. 口径卡（每个榜单的身份证）

```json
{
  "title": "影史最伟大的悬疑片",
  "criterion": "greatest",
  "definition": "以影史地位、形式创新与影响力为主，不按大众评分",
  "ranking_rule": "Sight & Sound 影评人榜前 60 ∪ TSPDT 前 60，按两榜名次和的升序，人工替换 18 部",
  "time_window": "1895–2024",
  "scope": {"kind": "global", "countries": []},
  "genres": [],
  "sources": [
    {"name": "Sight & Sound 2022 Critics", "url": "…", "weight": 0.6, "accessed": "2026-11"},
    {"name": "TSPDT 2025", "url": "…", "weight": 0.4, "accessed": "2026-11"}
  ],
  "inclusion_rule": "长片（≥40 分钟）；有可核实的公映记录",
  "exclusion_rule": "电视剧、合集、实验短片（另立榜单）",
  "known_bias": "英语中心；默片占比低；2010 年后作品偏少",
  "curator": "本项目",
  "version": "1"
}
```

前端在榜单页顶部固定展示 `title`、`definition`、`ranking_rule`、`known_bias` 四项，其余折叠。

### 2.1 收录门槛（"宁缺毋滥"的具体判据）

一部片进榜，至少要满足下面一条，并在 `note` 里点明是哪一条：

1. **影史地位**：被权威榜单或长期影评反复引用。
2. **形式创新**：在叙事、剪辑、摄影、美术、声音上开了新路。
3. **类型奠基**：定义了该类型的语法，或是该类型一次有分量的转折。
4. **奖项背书**：拿到 A / A− 级主奖，或对应类型的 C 级专项奖。
5. **持久影响**：持续被后来的作品、评论、观众引用或重拍。

一条都不满足的，删掉，由空位留在那里——**空位比凑数诚实**。条数因此不足 100 时，页面如实显示"收录 N 部"，并在口径卡的 `exclusion_rule` 里写明"未凑满，理由：候选池不足"。

## 3. 客观字段的主源与回退

| 字段 | 主源 | 回退 | 归一化 |
|---|---|---|---|
| 片名 | TMDb `title` / `original_title` | Wikipedia | 中英各存一份，不互相翻译 |
| 年份 | TMDb `release_date` | 人工 | 取首映年，多国上映冲突时记 `year_note` |
| 片长 | TMDb `runtime` | 人工 | 分钟整数；短片单列 |
| 国别 | TMDb `production_countries` | 人工 | ISO 3166-1 alpha-2；多国 → 首列为 `primary_country` |
| 导演 | TMDb `credits.crew` | 人工 | 存 `p:slug` 人物 id，不存纯字符串 |
| 类型 | TMDb `genres` | 人工 | 映射到本站三类型 + `other`，映射表在 `data/curated/genre-map.toml` |
| 票房 | Box Office Mojo / TMDb `revenue` | 无 | 名义美元；缺就是缺 |

`movie_key` 统一用 `tmdb:{id}`，没有 TMDb 记录的用 `imdb:{ttid}`，两者都没有的片子不进榜（宁缺毋滥）。

## 4. 评分：三源并存，不合并

- IMDb：大众基线，样本大，老片偏高。
- 豆瓣：中文圈，类型片与亚洲片更友好。
- Letterboxd：影迷分布，近年与作者电影偏高。

规则：

1. 每部片最多展示三个分，各自标源。
2. 榜单只能选**一个**评分口径（`imdb` / `douban` / `letterboxd`），口径卡里写清。
3. 不做加权平均——那会造出一个谁都不认的数。
4. 评分有抓取日期，榜单页标注"评分截至 YYYY-MM"。

## 5. 奖项维度

奖项是独立维度，不是榜单的附属。分级只按**含金量**，不按国家大小。

### 5.1 分级

| 级 | 含义 | 代表 |
|---|---|---|
| **A** | 全球公认、影响影史的奖 | 奥斯卡主要奖（最佳影片/导演/剧本/国际影片/表演/摄影/剪辑/音效/配乐）、戛纳金棕榈、威尼斯金狮、柏林金熊、BAFTA 最佳影片 |
| **A−** | 影响力大但争议明显 | 金球奖（剧情类/音乐喜剧类最佳影片）、戛纳评审团大奖、威尼斯/柏林评审团大奖 |
| **B** | 国家级最高奖 / 一线地区奖 | 法国凯撒、意大利大卫、西班牙戈雅、德国电影奖、欧洲电影奖、日本电影学院奖、《电影旬报》年度十佳、韩国青龙/大钟、华语三金（金马/金像/金鸡）、印度 Filmfare、墨西哥 Ariel、阿根廷 Sur、巴西 Grande Prêmio |
| **C** | 类型专项奖（与本站三类型直接相关） | 见 5.2 |
| **D** | 参考级，不进主榜单 | MTV 影视大奖、人民选择奖、各类观众票选 |

判定规则：

- 一部片只要拿到 A 或 A− 的任一主奖（不是技术小奖），即可进「获奖」榜的候选池。
- B 级奖项只在**本地区榜**里作为入选依据；不做跨地区权重比较。
- C 级奖项只进**类型榜**，不进综合榜。

### 5.2 三个类型对应的 C 级奖

| 类型 | 奖项 | 说明 |
|---|---|---|
| 悬疑 | 埃德加·爱伦·坡奖（Edgar Awards, MWA）最佳影片 | 推理/犯罪领域最权威 |
| 悬疑 | 日本推理作家协会奖（推理作家協会賞） | 亚洲推理最高 |
| 悬疑 | 马丁·贝克奖（Martin Beck Award, 瑞典） | 北欧犯罪小说/影视改编 |
| 科幻 | 雨果奖最佳戏剧表现（Hugo Award for Best Dramatic Presentation） | 科幻界最高荣誉之一，分长短片 |
| 科幻 | 土星奖（Saturn Awards）最佳科幻片 | 类型片工业奖 |
| 动作 | 土星奖最佳动作/冒险片 | 类型片工业奖 |
| 动作 | Taurus 世界特技奖（Taurus World Stunt Awards） | 动作片专业认可 |
| 动作 | 美国演员工会奖最佳特技群像（SAG Stunt Ensemble） | 工业认可 |

注意两个常见误判：**土星奖不是"科幻奥斯卡"**，它覆盖奇幻与恐怖；**雨果奖是科幻/奇幻混合**，入围作品不一定属于科幻，进榜前需人工确认类型。

### 5.3 奖项记录字段

```json
{"award":"oscar","tier":"A","year":1972,"category":"best_picture","result":"won",
 "movie_id":"m000123","person":null,"source":"academy"}
```

- `award` 用固定 slug，定义与 slug 表在 `data/curated/awards.toml`。
- `category` 也固定 slug，避免同一奖多种写法。
- `result` 只有 `won` / `nominated`；技术类小奖照收，但榜单默认只按 `won` 且 `tier ∈ {A, A−}` 计。
- 同一部片同一奖项多次获奖（如翻拍）按 `year` 区分。
- 首期人工维护，从各奖官网/Wikipedia 逐届录入；半自动抓取留到 M5 之后。

### 5.4 由此产生的榜单

| 榜单 id | 定义 |
|---|---|
| `awards-all-tripod` | 三大电影节主奖（金棕榈/金狮/金熊）获奖片，按获奖年份倒序 |
| `awards-all-oscar` | 奥斯卡最佳影片获奖片 |
| `awards-scifi-hugo` | 雨果奖最佳戏剧表现（长片）获奖片 |
| `awards-mystery-edgar` | 埃德加奖最佳影片获奖片 |
| `awards-action-stunt` | 土星动作/冒险 + Taurus 特技奖获奖片 |
| `awards-all-major` | A + A− 主奖并集，按"主奖数量 + 影史地位"排序，上限 100，不足如实 |

## 6. 三种特殊口径

**最早（上限 100）**：年份早不等于地位高。规则：按首映年升序、只收长片、标注 `survival:"complete|partial|fragment"`（存世状态），并把 1895 年前的实验影像单列附录。

**最长（上限 100）**：按片长降序；剔除剧集、合集、循环影像装置；短片另立一榜。超长实验片（>8 小时）单列，避免占满榜单。

**票房（上限 100）**：两种都不完美，一并展示——
- 名义票房（未调整）：现代表现最好，老片吃亏。
- 通胀调整票房（Box Office Mojo 的 adjusted gross）：仍是估算。
- 想表达"卖了多少张票"必须自己折算并标注"估算"，因为**票数从未公开**。榜单名写"估算售出票数"，别写成事实。

## 7. 地域：洲 → 国家

- 洲榜按 `primary_country` 归属，合拍片（`coproduction:true`）不进洲榜，另设"合拍"筛选。
- 国家榜只在有 ≥30 部候选的国家开放，否则显示"样本不足"，不硬凑 100。
- 洲际划分固定四组：亚洲、欧洲、美洲（含南北）、非洲；大洋洲并入亚洲榜附录，避免样本过少。
- 非洲需要单独说明：殖民时期影像档案缺失严重，榜单会显著偏向埃及、南非、塞内加尔、马里等有完整电影工业或作者传统的国家，这是数据现实，写进口径卡的 `known_bias`。

## 8. 版权与图片

- 海报仅用于榜单展示，来源标注在详情页（TMDb 图片页链接），不做热链、不二次分发。
- 海报本地缓存，构建期转 webp 并限制尺寸。
- 剧照只取每片 1–2 张，优先官方发布物料。
- 若将来商用，图片授权需重新评估——现在按"个人非商业项目"处理，并写进 README。

## 9. 数据质量门

上线前必须全过：

1. 每个榜单 `count == entries.length` 且 `count ≤ 100`；`rank` 从 1 连续无缺。**不要求凑满 100**。
2. 每部片必须有一句手记，且手记能说清"为什么它在榜上"；写不出就删掉这部，宁可少收。
3. 每部片都有 `year`、`runtime`、`primary_country`、至少一个 `title`（`missing` 显式列出缺项）。
4. 每个 `movie_id` 在主档存在；主档里的片至少出现在一个榜单或奖项记录中（无孤岛）。
5. 每个榜单有完整口径卡，`sources` 非空且带访问日期。
6. 奖项记录的 `award`/`category` 都在 `awards.toml` 里定义。
