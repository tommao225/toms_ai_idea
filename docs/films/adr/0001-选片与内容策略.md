# 选片与内容策略

## 背景

三个「最伟大」榜还没有定怎么选片。原型里每榜只放了一部示例，详情页的剧照和台词也还没有数据来源。选片办法决定 M0 的工作量和榜单的可信度；剧照和台词决定详情页要不要改结构。

## 决策

1. 选片用混合办法：先取权威榜（如 Sight & Sound、TSPDT）做骨架，再人工替换 15–25 部，每部写清替换理由。权威榜是起点，不是最终答案。
2. 剧照优先用真实剧照。达到「画面清晰、没有水印或字幕、对应正确影片、能标注来源」就用；达不到就用生成的占位图（海报主色 + 英文描边字），不用无关的图库图片冒充。
3. 台词保留。每部片至少一句台词或影评摘句，并标注出处；没有可核实出处的，用一句策展短句，标「策展」，不冒充台词。
4. 图片和短句按个人非商业项目处理：本地缓存、标注来源；商用前重新评估授权。

## 备选

| 方案 | 做法 | 为什么不选 |
|---|---|---|
| 直接引用权威榜 | 照抄权威榜，不替换 | 选片没有自己的观点，说不清这站为什么存在 |
| 完全自己算 | 用评分、奖项、名次加权 | 权重会被质疑，还要解释算法 |
| 首期不做剧照和台词 | 详情页只留海报和文字 | 产品需要保留台词板块；有真实剧照时效果更好 |

## 后果

- 选片阶段除了选片，还要每部筛一张剧照、录一句台词或摘句；工作量增加。
- 数据结构要补 `still`（剧照路径、来源、是否为占位）和 `quote`（文本、出处）。
- 管线要能抓剧照、判断质量、生成占位图；详情页要能区分真实剧照和占位。
- 剧照版权和台词引用要逐条标注来源，不能省略。
