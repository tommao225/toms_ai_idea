# 本地服务约定

适用于项目自带的本地服务或开发服务。占位符：`<默认端口>`、`<写接口>`、`<读接口>`、`<鉴权头>`、`<静态根>`、`<日志文件>`、`<PID 文件>`、`<单文件上限>`、`<单条目上限>`。

## 1. 运行形态与开关

- 默认只监听回环：`127.0.0.1:<默认端口>`。不默认绑定 `0.0.0.0`。
- 提供三种常规形态：后台常驻、前台调试、停止；另有一个**允许远程**的显式开关（形如 `--allow-remote`），默认关闭。
- 非回环地址必须显式开关才可监听；启动日志打印实际监听地址，不得由环境变量静默打开。
- 不做账号体系时，公网暴露前必须自建前置鉴权（反向代理认证或内网）；文档不推荐直接把编辑端开公网，隧道方案必须写明风险。
- 启动成功以「日志有新行 + 真实请求可达」为准，不以进程存在为准。

判据：回环地址 `curl` 可达；非回环地址默认不可达（拒绝连接或启动前报错退出）。

## 2. 改后端必须重启并用真实请求验证

- 路由、静态白名单、上传限制、内存缓存都在进程内，改完必须重启；否则跑的还是旧代码。
- 开发服务有热重载也要确认它真的生效；不确定就当没生效。
- 重启后确认是**新进程**：PID 变化、启动日志有新行、监听端口唯一。
- 用真实请求验证目标行为，不靠读代码或「看起来好了」；至少一条正常 + 一条负向。
- 重启失败要看到报错原文；不允许半启动（端口占用、PID 文件残留）。

判据：改动点能用一条 `curl` 复现「改前 / 改后」的差异。

## 3. 写接口的凭据与来源校验

- 读接口可放开（仍校验来源）；**写接口必须带凭据**：`<鉴权头>` 或同等机制。
- 凭据在启动时生成或从环境变量读取；不进仓库、不进日志、不进响应体、不拼进 URL。
- 写接口同时校验：凭据、`Content-Type: application/json`、`Origin` / `Host` 是否在白名单。
- 前端只在一处封装请求与头；页面里不手写请求、不手拼鉴权头。
- 凭据轮换 = 重启；不做跨进程长期复用的固定凭据。

判据：不带凭据、带错凭据访问 `<写接口>` 返回 401/403，且响应与日志都不回显凭据。

## 4. 静态资源白名单

- 只暴露白名单内的目录与入口文件；白名单外一律 404，不返回目录内容。
- **目录列表必须关闭**：没有索引页也返回 404，不列出文件。
- 默认禁止暴露：版本库目录、日志、服务源码与配置、构建/工具脚本、备份与临时文件、文档目录、数据中间产物。
- 不把仓库根作为 `<静态根>`。
- 新增公开目录要同步改白名单，并测两侧：白名单内 200、白名单外 404。
- 只对必要路径开放，不整目录放行整个资源父级。

判据：随机挑 3 个敏感路径请求，全部 404；白名单内文件全部 200。

## 5. 上传

- 双层校验：扩展名白名单 + 文件头 magic bytes；只看扩展名等于没校验。
- 上限：单文件 `<单文件上限>`、单条目 `<单条目上限>`；请求体超限直接拒绝，不落盘。
- 目标 id / 名称必须匹配 slug 规则，拼接后仍在上传根内（防目录穿越）；拒绝 `..` 与绝对路径。
- 保存用唯一临时名，成功后原子替换；失败清理临时文件与空目录。
- 返回相对路径，不回传服务器绝对路径与目录结构。
- 删除文件与删除记录是两个动作；删文件必须单独确认，不从记录删除连带推断。

判据：伪造扩展名的文件被拒；超限文件被拒且上传目录无残留。

## 6. 原子写入

- 落盘用「临时文件 + 原子替换」；临时文件名唯一（含随机后缀或 PID），不用固定 `.tmp`。
- 同一数据文件的写入加锁（线程/进程），并发请求不交叉覆盖。
- **先全量校验，再写**；校验失败不落盘。
- 多文件一次提交时，全部校验通过后再依次写；中途失败要能回到上一份完整数据，不留半份。
- 保留上一版备份便于回滚；备份不参与读取。
- 写入失败必须显式返回错误，不返回「成功」再把异常写进日志。

判据：并发两次写入后文件仍是完整合法结构；校验失败时文件与改动前逐字节一致。

## 7. 缓存、日志与进程管理

- 缓存分层：API 响应 `Cache-Control: no-store`；入口页面与数据文件 no-cache；静态资源短缓存；第三方依赖按路径前缀长缓存。
- 日志带时间戳与请求行；按大小轮转（保留上一份）；不打印凭据、完整请求体、完整 traceback（客户端断开这类异常只记一行）。
- `<PID 文件>` 记录实际进程；停止前校验命令行，避免 PID 复用误杀别的进程。
- 优雅停止超时后升级强杀；启动失败清理 PID 文件与端口占用。
- 前台模式日志打到终端；后台模式写 `<日志文件>`，保留末尾若干行供排查。

判据：重复启动不会出现两个实例；停止后 PID 文件不存在、端口已释放。

## 8. 安全底线

逐条可指认落在哪个开关、函数或请求上：

- [ ] 默认只监听回环，远程需显式开关
- [ ] 写接口有凭据校验，并校验来源与内容类型
- [ ] 凭据不出现在日志、响应、URL
- [ ] 静态资源白名单，目录列表关闭，仓库根未暴露
- [ ] 上传有扩展名 + 文件头 + 大小 + 路径四重校验
- [ ] 写入原子，校验失败不落盘
- [ ] 改后端后已重启，并用真实请求验证

## 9. 验证模板

按项目替换 `<默认端口>`、`<写接口>`、`<读接口>`、`<鉴权头>`、`<白名单外路径>`。

```bash
# 正常：回环读
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:<默认端口><读接口>

# 负向：无凭据写
curl -s -o /dev/null -w '%{http_code}\n' -X POST http://127.0.0.1:<默认端口><写接口>

# 负向：来源不在白名单
curl -s -o /dev/null -w '%{http_code}\n' \
  -H '<鉴权头>: <token>' -H 'Origin: <非白名单来源>' \
  -X POST http://127.0.0.1:<默认端口><写接口>

# 负向：内容类型错误
curl -s -o /dev/null -w '%{http_code}\n' \
  -H '<鉴权头>: <token>' -H 'Content-Type: text/plain' \
  -X POST --data '{}' http://127.0.0.1:<默认端口><写接口>

# 负向：白名单外静态路径
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:<默认端口>/<白名单外路径>
```

期望：正常 200；无凭据与错误来源 401/403；错误内容类型 400/415；白名单外 404。实际输出与期望不符即未完成。

## 10. 改动自查

- [ ] 已重启，验证的是新进程
- [ ] 正常请求与至少一条负向请求都实际跑过
- [ ] 白名单内、外两侧都测过
- [ ] 上传的伪造扩展名与超限文件都试过
- [ ] 并发写入后文件完整
- [ ] 日志里没有凭据与完整栈
- [ ] 停止后 PID 文件与端口都已释放

验证矩阵见 `./verification.md`；数据落盘规则见 `./data-and-assets.md`。
