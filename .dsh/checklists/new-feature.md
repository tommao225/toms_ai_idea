# 新功能开工清单

先判断扩展点属于哪一类（可多选），再按该类逐面同步。漏面通常表现为「能填但不显示」「能存但服务端拒绝」「新页面没入口」。

## 先定事实

- [ ] 这个功能落在哪个入口/哪个层级，是新入口还是扩展现有入口
- [ ] 哪些是纯逻辑，哪些是状态与 DOM
- [ ] 是否需要持久化；已有数据怎么兼容
- [ ] 是否已有相似能力可复用，能否扩展而不是新建
- [ ] 是否需要先写方案；需要就先写，并确认 P0、P1 都有结论（见 `../conventions/change-docs.md`）

## 1. 新增页面

要同步的面：入口、骨架、样式、数据加载、导航、静态白名单、文档。

- [ ] `<页面骨架>` 建立，样式在统一位置登记，没有页内私写全局样式
- [ ] 导航、路由、启动入口都加入口（含根入口）
- [ ] 数据加载走现有数据加载层，不新写一套请求
- [ ] 页面级布局复用既有骨架与容器宽度约定
- [ ] 新静态路径与资源已加入服务端白名单（本地服务场景）
- [ ] 空态、错误态、加载态、窄视口都检查
- [ ] 文档的目录树、页面说明、入口链接同步
- [ ] 从入口点进去实际走通一次

## 2. 新增数据字段

要同步的面：数据、写入表单、前端校验、服务端校验、消费端、迁移、文档。

- [ ] `<数据文件>` 或存储层补字段默认值或迁移路径，旧数据仍可读
- [ ] 表单读、写两侧都覆盖新字段，保存不静默丢弃
- [ ] 前端校验：类型、范围、必填、空值语义
- [ ] `<写接口>` 服务端校验与前端一致，非法值默认拒绝
- [ ] 所有消费端（展示、统计、导出、筛选）读取同一份定义
- [ ] 空值语义写清：空串、null、缺失分别代表什么
- [ ] 文档的数据格式示例同步
- [ ] 全链路验证：填写 → 保存 → 刷新 → 展示

## 3. 新增枚举类型

要同步的面：枚举定义、校验、选项、文案与图标、消费分支、默认值、文档。

- [ ] 枚举值集中在一处定义（`<常量文件>`），页面与服务端都从它取
- [ ] 既有数据补默认值或映射，未识别值有兜底分支而不是崩溃
- [ ] 表单选项、筛选项、排序与分组规则同步
- [ ] 每个取值对应的文案、图标、样式在同一批补齐
- [ ] 服务端校验接受新值并拒绝非法值
- [ ] 所有分支映射都覆盖新值，没有落到默认的静默分支
- [ ] 文档的取值表同步
- [ ] 新增值实际走一遍展示与回存

## 4. 新增共享组件

要同步的面：归属层、单一实现、调用点迁移、行为补齐、旧实现删除、回归。

- [ ] 先确认现有组件不能扩展，再新建
- [ ] 归属层判断：两个以上使用方 → 通用层或领域层；单一使用方 → 页面层
- [ ] 只保留一份实现，没有复制旧组件另起一套
- [ ] 所有旧调用点同批迁移，旧组件与其样式、选择器一起删除
- [ ] 键盘操作、Esc、焦点管理、滚动锁、无障碍属性按需补齐
- [ ] 空态、禁用态、错误态表现一致
- [ ] 所有消费方页面回归一次
- [ ] 删除后全仓搜索旧名，无残留引用

## 5. 新增接口或上传能力

要同步的面：路由、鉴权、入参校验、写入、调用端、静态策略、负向测试、文档。

- [ ] `<写接口>` 路由注册，权限/令牌校验与既有接口一致
- [ ] 入参校验：大小上限、类型、结构、允许值；非法即拒
- [ ] 写入原子化，失败不留半份数据与空目录
- [ ] 调用端有超时、失败提示、重复提交保护
- [ ] 上传内容按内容特征校验，不只看扩展名或文件名
- [ ] 静态白名单、缓存头、目录列表策略不受影响
- [ ] 负向测试：无凭据、坏来源、坏请求体、超限各一次
- [ ] 文档的接口说明与错误语义同步

## 6. 新增资源数据

要同步的面：来源、存放、加载、生成工具、离线、体积、文档。

- [ ] 资源来源、许可、体积登记在文档
- [ ] 存放位置符合既有目录约定，命名可预测
- [ ] 加载顺序与注册表与既有资源一致，不硬编码路径
- [ ] 生成脚本与校验脚本同批更新，产物可复现
- [ ] 重新生成后无差异；有差异说明来源变了，单独提交
- [ ] 断网/离线环境可加载
- [ ] 体积变化在可接受范围并已记录
- [ ] 文档的数据来源与体积同步

## 7. 完成前

- [ ] 走 `./change.md`
- [ ] 按 `../conventions/verification.md` 选验证面
- [ ] 汇报写清已验证 / 未验证 / 残留
