# 美术方向

> 这份写项目现在的视觉事实与资产计划。改动过程见 `../../docs/crucible/README.md`。

## 1. 目标观感

像把一台机器剖开，摆在灯下看。

三件事决定风格：

1. 侧视剖面。世界是一个横切面，有墙、有地、有厚度。
2. 低饱和环境配高饱和热源。铁灰、锈、黄铜压住画面，亮色只给火、岩浆和灯。
3. 材质像实物，不像色块。水有表面高光和波纹，沙有颗粒，蒸汽会飘。

参考《缺氧》的剖面工业感，《辐射：避难所》的边框与物件质感。目标落在两者之间：比缺氧重，比避难所冷。

## 2. 为什么这个方向与网格模拟兼容

- 世界本来就是侧视、一格一物质，与剖面同构，不需要为画风改玩法。
- 画面由四样东西叠出来：材质贴图、光照层、装置精灵、角色。不需要逐格动画。
- 缺氧的高级感主要来自光照与环境，不来自分辨率。

## 3. 视觉规则

| 项 | 规则 |
|---|---|
| 视角 | 严格正交侧视，一格 32 px，不做三四分之一透视 |
| 材质 | 每种物质一套 32×32 可平铺贴图，四个变体打散重复感 |
| 体积 | 每格与空格相邻的边压暗 20% 到 30%，做假环境光遮蔽 |
| 光照 | 世界默认暗，只有火、岩浆、加热器、灯具发光，光照层径向衰减后乘法混合 |
| 粒子 | 蒸汽、烟、火花、飞溅，共四到六种，飘散即消亡 |
| 装置 | 64 到 128 px 精灵，每个两到三个状态：关、开、过载 |
| 角色 | 48×64 px，四方向，每方向四到六帧 |
| 界面 | 钢与黄铜质感面板，等宽数字读数，图标化工具栏 |
| 调色 | 环境饱和度不超过 30%，热源允许高饱和 |
| 光源方向 | 统一左上，所有手绘资产同向，定下不改 |

## 4. 渲染架构

只画摄像机可见的格子，不画整张图。

1080p 下按 32 px 一格，可见约 60×34，两千格。两千个精灵对渲染层没有压力，所以材质可以做到 32 px 精细。

模拟与渲染解耦：模拟跑全图，可放 Web Worker；渲染只读可见区域。装置、光照、粒子和角色都不会拖慢模拟。

## 5. 资产清单

| 类别 | 数量 | 规格 |
|---|---|---|
| 物质材质 | 9 种各 4 变体，共 36 | 32×32 可平铺 |
| 装置精灵 | 8 种各 2 到 3 状态，约 20 | 64 到 128 px |
| 角色 | 二到四名，每名约 40 帧 | 48×64 px |
| 粒子 | 6 | 16×16 |
| 背景剖面 | 1 到 3 | 远景厂房，可平铺 |
| 界面 | 边框九宫格、按钮、图标，约 30 | 优先 SVG |

合计约 200 个小资产，其中一半是角色帧。

## 6. 分级推进

| 级别 | 内容 | 验收 |
|---|---|---|
| L0 灰盒 | 纯色、假环境光遮蔽、一个光源 | 看得出物质在动，能截图对比 |
| L1 有质感 | 材质贴图、光照层、粒子 | 与参考截图并排，材质能分辨 |
| L2 有物件 | 装置精灵、角色、界面皮肤、背景 | 一眼不像原型 |

每一级都能独立截图，风格问题不阻塞玩法开发。

**现在到哪一步**：L0 完成，L1 用程序化手段做了三件（见下一节），L2 只做了装置和角色的点阵图标。没有任何外部美术资产，全靠代码画。

## 6.1 已经落地的程序化视觉

| 手段 | 做法 | 效果 |
|---|---|---|
| 亮度抖动 | 每格按坐标哈希取四档亮度之一 | 大片同色物质不再像油漆桶，沙子和石头有颗粒感 |
| 受光面 | 上方是空气的格子提亮 28% | 堆积物有顶面，看起来有厚度 |
| 高温发光 | 温度超过 320 度的格子往暖白偏 | 岩浆和火自己会亮，代替真正的光照层 |
| 装置图标 | 每种装置 5×5 点阵，'#' 本体、'+' 暗轮廓 | 八种装置各有轮廓，不再是同色方块 |
| 角色 | 3×7 的小人：头、身、两条腿，拿东西时变黄 | 看得出人形，也看得出手上有没有货 |
| 界面 | 面板阴影、按钮悬停、画面暗角 | 不抢画面，但不像默认样式 |

这些全部在渲染层算，不依赖任何图片资源。以后有真素材时，替换贴图不影响玩法代码。

## 6.2 还没做的

- 真正的贴图集与光照层：现在的高温发光只是颜色偏移，不是光照传播。
- 粒子：蒸汽、烟、火花都还没有。
- 背景剖面：画面上除物质以外还是空的。

## 7. 资产来源

| 来源 | 成本 | 风格控制 | 风险 |
|---|---|---|---|
| CC0 素材拼贴 | 低 | 中 | 拼贴感，需要统一调色 |
| 付费素材包 | 低到中 | 中 | 与自绘部分拼不齐 |
| 外包画师 | 数千元，两到三周 | 高 | 排期风险，需要美术规范 |
| AI 生成加手修 | 低到中 | 中 | 平台要求标注 AI，一致性差 |

具体渠道：

- 免费：Kenney、OpenGameArt、game-icons、CraftPix 免费区。
- 付费：CraftPix 会员、itch 付费包、GameDevMarket。
- 约稿：米画师（国内）、ArtStation（海外）、Fiverr。
- AI：只做概念草图与氛围参考，最终资产不用。

选择：材质与背景用 CC0 拼贴加调色；角色、装置和界面花一次钱外包或买现成包；AI 只做草图。

先买一套含动画的 2D 小人物包，比从零约稿便宜一个数量级，也能先把动画规格和管线的坑踩完。

外包的前提是一份美术规范：色板、材质对照表、装置造型语言，同一套螺栓、面板线和警示条纹，以及统一的光源方向。没有它，多批资产拼不到一起。

## 8. 小人

不做。角色与操作员已移除，画面里只有物质和装置。

| 动作 | 帧数 | 说明 |
|---|---|---|
| 待机 | 2 | 呼吸起伏 |
| 走 | 4 到 6 | 四方向 |
| 搬 | 2 | 抱物行走 |
| 操作 | 2 | 按开关、扳阀门 |

每名角色约 40 帧。优先用现成含动画的小人物包改配色与配件，其次约稿，最后才考虑从零手绘。

不做：需求系统、寻路、日程、表情、换装。

## 9. 观感验收

1. 灰盒截图与 L2 截图并排，能看出材质差异、有明暗、有光源。
2. 画面缩到四分之一仍能认出这是剖面厂房，不是色块网格。
3. 不看界面也能判断哪里热、哪里有流动。
4. 角色在场景里能看出走、搬、操作三种动作。
