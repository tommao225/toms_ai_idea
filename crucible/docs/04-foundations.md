# 运行时与数据契约

> 这份写项目现在约定的运行规则与数据边界。目录结构见 `03-architecture.md`，改动过程见 `../../docs/crucible/README.md`。

## 1. 时间

| 项 | 值 | 说明 |
|---|---|---|
| 模拟步长 | 每秒 20 tick | 与渲染帧率解耦，只在一处定义 |
| 渲染 | 跟随屏幕刷新，用两次 tick 之间插值 | 渲染不推进世界 |
| 慢放 | 每 N 帧走 1 tick | 只改速度，不改规则 |
| 单步 | 手动触发 1 tick | 调试与解谜共用同一入口 |
| 暂停 | 不推进 tick | 仍可悬停与布置 |

规则：

- 模拟里不读系统时间，时间只用 tick 计数表达。
- 插值系数只在表现层用，不回写模拟。
- 时长要么用 tick 要么用秒，换算只写在一处，变量名带上单位（`ticks`、`seconds`）。

判据：把慢放改成四分之一速，同一局的结果完全相同。

## 2. 命令与状态

外部改动世界的唯一通道是命令：

```
界面点击 → 生成命令 → app 派发 → 世界执行 → 事件通知
```

- 命令是纯数据对象，可序列化，不是函数。
- 世界对外只暴露两样东西：`WorldView` 只读查询，与命令入口。不暴露可变的内部数组。
- `render/` 与 `ui/` 只拿 `WorldView`，拿不到写权限。

判据：在 `render/` 与 `ui/` 里搜不到对世界状态的赋值。

## 3. 快照、撤销与回放

- 每条命令执行前存一份快照，撤销就是回退到上一份。
- 快照含：网格、温度、装置表、tick、随机种子。
- 预算：单份不超过 2 MB，撤销栈最多 30 份，超了丢最老的。
- 回放 = 初始快照加命令序列，不逐帧存。

判据：连续撤销 20 步，与当初逐步前进的状态逐格一致。

## 4. 存档与版本

- 存档含格式版本、种子、tick、世界快照。设置不进存档。
- 格式版本与数据版本分开记；读档先升级再加载。
- 读档失败要能退回上一份备份，报可读的错误，不静默重置。
- 存储入口只有 `app/save.ts` 一处；浏览器用 IndexedDB，桌面走用户目录。

判据：删掉旧存档里的一个可选字段，仍能读入并补默认值。

## 5. 数据契约

- `data/` 下每个文件带 `id` 与 `schemaVersion`。
- 启动逐条校验，报错指到文件与字段；缺必填就拒绝启动，不带病运行。
- 校验与读取共用同一模块，不各写一份。
- 数据只加不删；要删先写迁移。

判据：故意删一个必填字段，启动时能看到文件名与字段名。

## 6. 事件

- 事件是通知，不是控制流。处理函数里不修改世界。
- 事件名与载荷只在 `src/events.ts` 定义。
- 事件带 tick 与来源，便于回放与排查。
- 音频、日志、成就都只订阅事件。

判据：删掉所有订阅者，游戏行为不变。

## 7. 线程边界

- v1 模拟跑在主线程，但只通过 `SimClock` 接口调用。
- 以后搬进 Web Worker，只换 `SimClock` 的实现，编排代码不动。
- 接口只传命令与快照，不传对象图。

判据：`app/` 之外没有地方直接调用世界的步进函数。

## 8. 可观测性

- 开发面板显示：帧率、tick 耗时、格子数、装置数、随机种子。
- 反应日志保留最近若干条：tick、位置、反应名。
- 模拟抛错就暂停并显示错误，不静默跳过。
- 热路径不分配临时对象，命令对象用池，每 tick 的分配接近零。

判据：不打断点，只看面板能判断卡在哪一环。

## 9. 测试

| 类型 | 做什么 | 通过标准 |
|---|---|---|
| 规则单测 | 一条反应：给定输入格，一 tick 后看输出格 | 每条反应都有用例 |
| 场景快照 | 固定初始状态跑 N tick，比较网格哈希 | 哈希变化必须是有意的 |
| 不变量 | 反应前后物质总量守恒，扣除显式转化 | 随机跑 100 局不破 |
| 依赖方向 | 静态检查 import 是否符合分层表 | 零违规 |

## 10. 设置、文案与可访问性

- 设置项集中在一张表里：键、类型、默认值、范围。读取时归一化。
- 所有界面文案走 `data/strings/zh.json`，代码里不出现中文字符串。
- 物质不能只靠颜色区分：每种物质有不同纹理，悬停有名字。
- 界面缩放与减少动效两个开关先留位置。

判据：全仓搜中文字符串，只命中 `data/strings/` 与注释。

## 11. 内容编辑

- 编辑器到 W3 后再做，且只是开发工具，不进正式包。

判据：新增一种物质或一种装置只加数据文件，不改代码。

## 12. 发布、依赖与素材许可

- 版本号同时写进界面角落与存档；构建产物带提交短哈希。
- 未完成内容用开关隔离，只在开发构建设置生效。
- 第三方依赖只留 Vite、TypeScript、PixiJS、Vitest；新增依赖要说清替掉了多少行。
- 素材逐个记来源与许可，集中放 `assets/CREDITS.md`。

判据：从零拉仓库，一条命令能出可上传的构建。

## 13. 现在定与以后定

| 项 | 什么时候定 | 现在做错会怎样 |
|---|---|---|
| 时间模型、命令通道、确定性 | 现在 | 撤销、回放、测试全部要重写 |
| 快照格式与预算 | 现在 | 撤销做不出来，或吃光内存 |
| 世界只读视图 | 现在 | 渲染与界面长进世界内部，改不动 |
| 数据校验与版本 | W1 | 数据错一处，运行到一半才炸 |
| 线程边界 | 现在留接口，以后换实现 | 后期搬 Worker 要改编排 |
| 调试面板 | W0 | 出问题只能靠猜 |
| 存档迁移 | 第一次改数据结构时 | 老档全废 |
| 内容编辑器 | W3 之后 | 手写坐标会越来越痛 |
| 多语言、成就、联机 | 不做 | 现在做属于提前背债 |
